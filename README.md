# Realitní kvíz RE/MAX Delta

Interaktivní kariérní diagnostika „Máte předpoklady stát se realitním makléřem?“.

## Co aplikace obsahuje

- 10 situačních otázek
- hodnocení: obchodní tah, odolnost, disciplína a práce s lidmi
- kontaktní formulář před zobrazením výsledku
- interní klasifikaci leadu A/B/C
- přenos UTM parametrů kampaně
- responzivní design pro mobil i počítač

## Sběr kontaktů

V souboru `index.html` je konstanta `LEAD_ENDPOINT`. Po vložení adresy Google Apps Scriptu, Make webhooku nebo CRM endpointu se výsledky začnou odesílat do zvoleného systému. Do té doby se testovací výsledek ukládá pouze lokálně v prohlížeči.
